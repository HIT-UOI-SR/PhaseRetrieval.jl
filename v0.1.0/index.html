PhaseRetrieval

Classic phase retrieval algorithms.

Optical propagation

PhaseRetrieval requires Julia 1.10 or later and depends on OpticalPropagation 0.4 for optical propagation. Pass a forward/backward propagation pair to the projector keyword. OpticalPropagation's fresnel2 uses the same physical grid in both directions, and its curried form accepts unitful propagation distances.

The following executable example starts with a zero phase estimate. The input is a MonoLightField2D, so wavelength, window size, and window centre are retained during the iterations:

using PhaseRetrieval, OpticalPropagation, Unitful

data = [exp(-3 * (x^2 + y^2)) * cis(0.8x^2 - 0.6y)
        for x in range(-1, 1; length=9), y in range(-1, 1; length=8)]
truth = MonoLightField2D(data; wavelength=532u"nm",
                        size=(0.8u"mm", 0.6u"mm"),
                        center=(0.2u"mm", -0.1u"mm"))
forward, backward = fresnel2(20u"mm"), fresnel2(-20u"mm")
measured = forward(truth)
recovered, output = gerchbergsaxton(abs.(truth), abs.(measured);
    projector=(forward, backward),
    init=MonoLightField2D(truth; data=abs.(parent(truth))),
    maxiter=30)

@assert physicalsize(recovered) == physicalsize(truth)
@assert gridcenter(recovered) == gridcenter(truth)
@assert abs.(parent(recovered)) ≈ abs.(parent(truth))

Use matching sampling grids for the amplitude measurements and propagators. The first returned field satisfies the input amplitude constraint, and the second is its forward propagation. At a finite iteration count, the output amplitude need not match the measured amplitude exactly. Light-field support is part of the package's main module. abs.(light) and abs2.(light) retain OpticalPropagation's complex storage; the solvers accept these measurements only when every value is real, finite, and nonnegative. All five solvers preserve the light-field metadata when using propagation functions that return light fields.

For fixed-grid Fresnel propagation, backward propagation is also the Hermitian adjoint. Supply it to Yang–Gu with normaldiag=1. HIO and RAAR accept the same forward/backward pair, plus an ordinary Boolean support. With wrapped detector measurements, their default initialization uses the detector grid; supply an init light field when the object has a different physical grid.

yg, ygoutput = yanggu(abs.(truth), abs.(measured);
    projector=(forward, backward), normaldiag=1,
    maxiter=3, inneriter=2)
support = trues(size(truth))
for solver in (hio, raar)
    field, prediction = solver(abs.(measured), support;
        projector=(forward, backward), init=copy(truth), maxiter=3)
    @assert prediction ≈ forward(field)
    @assert gridcenter(field) == gridcenter(truth)
end

distances = (7u"mm", 13u"mm")
pairs = [(fresnel2(d), fresnel2(-d)) for d in distances]
planes = [truth, fresnel2(distances[1])(truth), fresnel2(sum(distances))(truth)]
fields = sbmir([abs2.(plane) for plane in planes];
    propagators=pairs, init=copy(truth), maxiter=3)
@assert fields[2] ≈ pairs[1][1](fields[1])
@assert fields[3] ≈ pairs[2][1](fields[2])

OpticalPropagation 0.4 provides the FFT grids, signed-distance phases and independently sampled Rayleigh–Sommerfeld propagation. PhaseRetrieval uses those operators directly, including fresnel2's global carrier phase. The integration tests exercise rectangular odd/even grids and signed propagation distances.

A finite-window or independently sampled Rayleigh–Sommerfeld operator is generally nonunitary. Use Yang–Gu with its actual discrete Hermitian adjoint and normaldiag=diag(G'G); propagating by a negative distance does not construct that adjoint. The matrix interface can use a discretized propagation matrix G, including rectangular matrices for different input/output sample counts. The integration tests compare a wrapped Rayleigh–Sommerfeld forward/adjoint pair to this matrix interface, checking each plane's sampling and metadata.

Data and return conventions

gerchbergsaxton, yanggu, hio and raar accept amplitudes (sqrt.(I) for camera intensities). sbmir accepts intensities and takes the square roots internally. Initialization is a field, not an array of phase angles: pass exp.(im .* phase) to initialize from a phase map. Inputs are not modified.

Two-plane solvers return (field, forward(field)). GS and Yang–Gu enforce the input amplitude on field; HIO and RAAR return their raw feedback iterate. Their output-plane fields are predictions, not amplitude-clamped intermediates. SBMIR returns a vector of predictions from its final first-plane field.

For an object constrained to a support, extract an estimate with ifelse.(support, field, zero(eltype(field))). If nonnegative, use ifelse.(support, max.(real.(field), 0), 0.0). Check the propagation residual of this estimate as well as the raw iterate. A RAAR fixed point for inconsistent constraints need not be a feasible object.

All solvers support maxiter=0. Setting tol=0 forces exactly maxiter updates; otherwise stopping uses the supplied errorfunc (mean squared difference by default). GS and Yang–Gu check predicted output amplitude error. HIO and RAAR also check the distance to the object constraint. SBMIR checks amplitude error at every plane using unconstrained forward predictions of the same field. Tolerances are absolute, in the units of the selected error function.

The original GS keywords and tuple structure remain supported, but the second return value now equals the forward transform of the returned first value. Previously it was an amplitude-clamped intermediate from a different point in the iteration. GS now copies init and always enforces the input amplitude, including early exits; its error test is now in the output plane.

Update equations

Write $P_a(z)=a\,\mathrm{phase}(z)$, with phase zero chosen when $z=0$. For a scaled unitary forward operator $F$, let $P_M(x)=F^{-1}P_b(Fx)$. The default (fft, ifft) uses Julia's unshifted FFT ordering, with no implicit fftshift or intensity normalization.

Gerchberg–Saxton: $x_{k+1}=P_a(P_M(x_k))$. A custom non-mutating pair is passed as projector=(forward, inverse).

Yang–Gu: let $W=G^*G=D+W_{\mathrm{off}}$, where $D$ is its diagonal. At each outer step hold $v=P_b(Gx_k)$ fixed and perform the inner iteration

\[x^{(m+1)}=P_a\left(G^*v-W_{\mathrm{off}}x^{(m)}\right).\]

At a vanishing argument the previous phase is retained. For $G^*G=cI$ the off-diagonal part vanishes and the method reduces to GS. The implementation computes $W x$ via forward and adjoint applications, without storing a dense Gram matrix. The matrix interface uses Julia column-major vectorization. For a matrix-free operator supply projector=(forward, adjoint) and normaldiag=diag(G'G) reshaped like Ain (or a scalar for a constant diagonal). Using the inverse in place of the adjoint is incorrect for a nonunitary system. This is the unweighted simultaneous inner iteration; poorly conditioned operators can cause stagnation or oscillation. inneriter and innertol control the inner loop separately from the outer measurement error.

HIO: with $p=P_M(x_k)$, accept $p$ inside support $S$ and apply $x_k-\beta p$ outside. With nonnegative=true, accepted pixels must also have $\Re(p)\geq0$ and are replaced by $\Re(p)$; other pixels receive feedback. This option models a real nonnegative object; support alone permits complex fields.

RAAR: with $R_S=2P_S-I$ and $R_M=2P_M-I$, use

\[x_{k+1}=\frac{\beta}{2}(R_S R_M x_k+x_k)+(1-\beta)P_Mx_k.\]

$P_S$ zeros the exterior of the support and optionally projects its interior onto the nonnegative real axis. It acts on the reflected field $R_M x_k$. At $\beta=0$ this becomes $P_M$; at $\beta=1$ it becomes averaged alternating reflection. HIO and RAAR retain feedback after the final update. They do not silently append error-reduction steps.

SBMIR: initialize the first plane with $\sqrt{I_1}$ and the initial phase. Propagate successively to each plane, replacing amplitude by $\sqrt{I_j}$. Then traverse the planes backwards, enforcing each visited amplitude again. One iteration is the complete forward/backward sweep. For two planes this is GS with the specified propagation pair. Custom adjacent-plane pairs are passed as propagators=[(forward12, backward21), (forward23, backward32), ...].

Multi-plane reconstruction with OpticalPropagation

For plain two-dimensional real measurement matrices, the positions interface converts pixel spacing to physical window widths and calls OpticalPropagation.fresnel2 at each adjacent distance. All lengths in this interface are in metres. It uses OpticalPropagation's full propagation phase. Choose adequate sampling and padding for the optical field. For light fields and unitful distances, use the propagation functors shown above.

using PhaseRetrieval, OpticalPropagation, Random
Random.seed!(104)
truth = (0.6 .+ rand(8, 9)) .* exp.(0.7im .* randn(8, 9))
z = [0.0, 0.8, 2.1, 3.9, 6.2]
optics = (wavelength=0.08, pixelsize=(0.2, 0.25))
widths = size(truth) .* optics.pixelsize
I = [abs2.(fresnel2(truth, d, optics.wavelength, widths...)) for d in z]
fields = sbmir(I, z; optics..., init=ones(size(truth)), maxiter=250)
phase = angle.(fields[1])
errors = [sum(abs2, abs2.(u) .- measured) / length(u)
          for (u, measured) in zip(fields, I)]

These methods solve nonconvex problems: convergence and uniqueness are not guaranteed. Phase comparisons should account for a global phase offset, and support-only Fourier retrieval can additionally have translation and conjugate inversion ambiguities. The tests separately verify update formulas, fixed points, reduction to simpler algorithms, and recovery from independent initial estimates; fixed-point tests alone cannot establish recovery performance.

PhaseRetrieval.gerchbergsaxton — Method
gerchbergsaxton(Ain, Aout; maxiter=100, projector=(fft, ifft),
               errorfunc=msd, tol=eps(), init=nothing)

Recover a complex field from two amplitude measurements using Gerchberg–Saxton. For intensity measurements, pass their square roots. projector contains a non-mutating forward transform and its inverse (normally a scaled unitary pair). The default FFT uses unshifted frequency ordering and Julia's FFT normalization.

Return (field, propagated), where abs.(field) ≈ Ain and propagated = projector[1](field). The latter is a prediction, not an amplitude clamped array: its residual against Aout measures consistency. Stop when errorfunc(abs.(propagated), Aout) <= tol, or after maxiter updates. tol=0 disables early stopping. maxiter=0 returns the amplitude-constrained initial estimate and its propagation. init is a field estimate (only its phase is used), defaults to random phase, and is never modified.

References

  1. R. W. Gerchberg and W. O. Saxton, "A practical algorithm for the determination of the phase from image and diffraction plane pictures," Optik 35, 237 (1972)

PhaseRetrieval.hio — Method
hio(Aout, support; beta=0.9, nonnegative=false, projector=(fft, ifft),
    maxiter=100, errorfunc=msd, tol=eps(), init=nothing)

Fienup hybrid input–output phase retrieval from a measured amplitude and a Boolean object support. With p = inverse(Aout .* phase(forward(x))), accept p inside the support and use x - beta*p outside. For nonnegative=true, accept real(p) only inside the support where real(p) >= 0; use feedback on all remaining pixels. This option assumes a real, nonnegative object.

Return the raw final iterate and its propagation (x, forward(x)). Feedback outside the support is deliberately retained. To form a support-constrained estimate use ifelse.(support, x, zero(eltype(x))) (and clamp its real part if nonnegative). init is copied without projecting; the default random field is projected onto the object constraint. The forward/inverse pair must be non-mutating and scaled unitary. Stop only when both the predicted amplitude MSD and object-projection MSD are at most tol. errorfunc replaces MSD in both tests. tol=0 forces maxiter updates; maxiter=0 returns the initial iterate. 0 <= beta <= 1.

Reference: J. R. Fienup, Applied Optics 21, 2758–2769 (1982), doi:10.1364/AO.21.002758.

PhaseRetrieval.raar — Method
raar(Aout, support; beta=0.9, nonnegative=false, projector=(fft, ifft),
     maxiter=100, errorfunc=msd, tol=eps(), init=nothing)

Relaxed averaged alternating reflections using x_next = beta/2 * (R_S(R_M(x)) + x) + (1-beta)*P_M(x), where R = 2P-I, P_M imposes the measured amplitude, and P_S imposes the Boolean support and optionally real nonnegativity. In particular, nonnegativity is applied to the reflected field, not to P_M(x).

Return (x, forward(x)) with the raw iterate, retaining relaxation feedback. Arguments, stopping, initialization, and support-estimate extraction follow hio. beta=0 is the modulus projection; beta=1 is averaged alternating reflection.

Reference: D. R. Luke, Inverse Problems 21, 37–50 (2005), doi:10.1088/0266-5611/21/1/004.

PhaseRetrieval.sbmir — Method
sbmir(intensities; propagators, maxiter=100, tol=eps(), errorfunc=msd, init=nothing)
sbmir(intensities, positions; wavelength, pixelsize, kwargs...)

Single-beam multiple-intensity reconstruction (SBMIR). intensities is a vector or tuple of at least two real nonnegative arrays containing intensities; the algorithm uses their square roots as amplitude constraints. init is a field estimate at the first plane; only its phase is used.

Supply one non-mutating (forward, backward) propagation pair per adjacent pair of planes. An iteration visits 1 → 2 → … → N → … → 2 → 1, imposing each visited plane's amplitude. Alternatively, supply strictly monotone plane positions, a wavelength, and pixelsize for two-dimensional matrix measurements. This convenience interface calls OpticalPropagation.fresnel2 for each adjacent distance, including its carrier phase. Lengths are in metres; pixelsize is a scalar or a pair in array-dimension order. These measurements must share a grid. For MonoLightField2D measurements, pass OpticalPropagation's unitful propagation functors through propagators.

Return a vector of mutually consistent predicted complex fields, generated by propagating the final first-plane estimate. Only its amplitude is enforced on return. Stop when the amplitude error at every predicted plane is at most tol. tol=0 disables early stopping; maxiter=0 returns predictions from the amplitude-constrained initialization. No input array is modified.

Reference: P. Almoro, G. Pedrini and W. Osten, Applied Optics 45, 8596–8605 (2006), doi:10.1364/AO.45.008596.

PhaseRetrieval.yanggu — Method
yanggu(Ain, Aout, G; kwargs...)
yanggu(Ain, Aout; projector=nothing, normaldiag=nothing,
       maxiter=100, inneriter=10, innertol=eps(), tol=eps(),
       errorfunc=msd, init=nothing)

Yang–Gu phase retrieval from two amplitude measurements for a general linear transform. A matrix G acts on vec(field) in Julia column-major order and may be rectangular or singular. Alternatively, supply projector=(forward, adjoint) and normaldiag = diag(G'G) as a scalar or an array shaped like Ain. The second operator is the Hermitian adjoint, not the inverse. With neither keyword supplied, use (fft, bfft) and normaldiag=length(Ain).

For each outer step set v = Aout .* phase(G*u). Holding v fixed, perform up to inneriter simultaneous inner updates u = Ain .* phase(G'*v - (G'*G - Diagonal(normaldiag))*u). At a zero update argument retain the previous phase. This is the unweighted Yang–Gu inner iteration; convergence is not guaranteed for every nonunitary operator. For a scaled unitary transform it reduces to Gerchberg–Saxton. innertol bounds the mean squared complex change within the inner loop; zero disables that stopping test. inneriter must be positive.

Return (field, forward(field)). Initialization, outer stopping, tol=0, and maxiter=0 follow gerchbergsaxton. Inputs are never modified.

Reference: G.-Z. Yang et al., Applied Optics 33, 209–218 (1994), doi:10.1364/AO.33.000209.
